# Cloudy VPS v1.0-dev — начни здесь

Это Python-бот с настоящим управлением Docker-контейнерами. Интерфейс Discord на английском.
В этом ZIP **нет твоего Discord-токена или API-ключа**. Ничего в твоих аккаунтах не создано.

## Сначала безопасность

1. В Discord Developer Portal → приложение → Bot → **Reset Token** перевыпусти раскрытый токен.
2. В Freestyle отзови раскрытый API-ключ и создай новый. Не вставляй новые ключи в чат.
3. Скопируй `.env.example` в `.env`, впиши новый токен и реальные ID сервера, канала `#deploy` и роли тестировщика.
4. Реальный `.env` не загружай на GitHub. `.gitignore` уже настроен; `.env.example` содержит только заглушки.

## Что нужно для запуска

**Один VPS пользователя по умолчанию:** 15 GiB RAM, квота 3 vCPU, 75 GiB записываемого диска, Ubuntu 22.04.
GiB — двоичные единицы. Это лимиты контейнера, а не выделенные физические ядра и не отдельная VM.

**Хост для такого плана:** Linux VM с root, systemd, Docker, cgroups и примерно **4 vCPU / 20 GiB RAM / 128 GiB диска**.
Установщик создаёт заранее выделенный 100 GiB XFS-диск для Docker. Должно быть достаточно настоящего свободного места.
По умолчанию открыт **1 слот** на ноде; не увеличивай MAX_VPS_TOTAL без дополнительной мощности.

На бесплатном Freestyle одна VM ограничена 8 GiB RAM и 32 GB диска по проверенной документации.
Поэтому запрошенный большой план на Free **не помещается**. Больший хост может требовать платный тариф;
проверь стоимость и ограничения своего аккаунта **до** запуска. Вечная бесплатная работа не обещается.

## Два способа размещения

- **Freestyle:** открой `docs/FREESTYLE_RU.md`. Есть отдельный установочный скрипт для новой VM и вариант ручной установки.
- **Свой сервер:** выполни инструкции в `README.md` на свежей выделенной Ubuntu VM.

Команды: `$deploy` в `#deploy`, `$manage`, `$status`, `$help`.
Кнопки: Start, Stop, sshx · DM, Stats, Refresh, Reinstall.

**Не запускай код вслепую:** установочные скрипты меняют конфигурацию Docker и добавляют изоляционные правила firewall.
Они рассчитаны на свежую выделенную VM, не на сервер с существующими сайтами или данными.

## Статус проверки

Читай `docs/TEST_REPORT.md`: какие проверки действительно выполнены и что ещё нужно проверить на твоей VM.
Docker, Discord и Freestyle не были запущены в среде сборки; это не подтверждённое production-развёртывание.
